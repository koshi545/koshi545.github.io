プライバシーポリシー

このアプリは運営者本人だけが使う個人用ツールです。

  • Google アカウントへのアクセスは Gmail の読み取り専用権限（gmail.readonly）に限ります。メールの送信・変更・削除は行いません。
  • 取得したメールは、運営者本人のための要約と保存にだけ使います。
  • 取得したデータを第三者に販売・提供することはありません。
  • Google API から取得したデータの利用は、Google API Services User Data Policy（Limited Use 要件を含む）に従います。

Privacy Policy

This app is a personal tool used only by its owner.

  • Access to the Google account is limited to read-only Gmail (gmail.readonly). The app never sends, modifies, or deletes email.
  • Retrieved email is used only to summarize and archive newsletters for the owner.
  • Data is never sold or shared with third parties.
  • Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
